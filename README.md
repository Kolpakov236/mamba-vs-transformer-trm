# Mamba vs Transformer in Tiny Recursive Model

A team experiment on replacing attention with Mamba in Tiny Recursive Model for ARC-AGI-2, carried out at the Mathematics in AI student camp.

- [Original notebook on Kaggle](https://www.kaggle.com/code/alephir/mamba-vs-transformer-trm)
- [Colab source](https://colab.research.google.com/drive/1Po02qQcUzb--wRcvwbzvuxA-A3_NBoPp)
- [Notebook in this repository](notebooks/mamba-vs-transformer-trm.ipynb)
- [Team presentation](https://disk.yandex.ru/i/2SSg3KvFAeyMIQ)

The notebook includes the model blocks, dataset configuration, training and evaluation code, and the original cell outputs. This was a pilot under a short training budget. It does not establish an advantage for either architecture.
